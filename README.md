# monoflowers.ge — ყვავილების მაღაზიის კატალოგი

სტატიკური საიტი Astro 5-ზე. ჰოსტინგი: Cloudflare Pages (build: `npm run build`, output: `dist`).

## ადმინ პანელი
გახსენი https://app.pagescms.org, შედი GitHub-ით და აირჩიე `monoflowers`.
- **პროდუქცია** — დაამატე ან შეცვალე პროდუქტები (ფასი, ფოტოები, კატეგორია, მარაგი).
- **საიტის პარამეტრები** — ტელეფონი, WhatsApp, Instagram, მისამართი, სამუშაო საათები.

ფოტოები ინახება `public/images`-ში. ნიმუშის პროდუქტები (`example-*.md`) ნამდვილით უნდა ჩაანაცვლო ან წაშალო.

## ლოკალურად გაშვება
```
npm install
npm run dev
```
